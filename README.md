# Weiterwerk Bildungszentrum

Fictional education and adult vocational training template, built for a sector-specific outreach portfolio. Programmes, durations and people are illustrative; this is not an actual training provider and makes no accreditation or funding claims.

## Features

- German / English interface and programme details.
- Five example programmes across retraining, skills development and career coaching.
- Category and learning-format filters, result count, empty state and reset.
- Expandable curricula and programme-specific consultation selection.
- Interactive funding-orientation explainer with an official Federal Employment Agency source.
- Three-step learner journey and FAQs.
- Browser-local consultation preview; no email, booking, backend submission or collection of contact information.
- Self-hosted fonts, one AI-generated adult-training photograph, reduced-motion support.

## Local preview

From this directory run `portless`, then `portless get weiterwerk-bildungszentrum`. The server honours Portless PORT and HOST. No dependencies or build are required.

## Check and deploy

`npm run check` verifies JavaScript syntax. Vercel serves `dist` directly using `vercel.json`.

## Adaptation checklist

Replace the fictional brand and photograph, verified programmes, duration, entry requirements, learning formats, location and actual consultation destination for each approved client project. Add qualifications or funding eligibility only when verified for that provider and programme. Keep demo-only behaviour clearly identified until a real contact integration is implemented.

Asset provenance and the exact image prompt are in ASSETS.md. PRODUCT.md and DESIGN.md describe the product and inherited visual system.
